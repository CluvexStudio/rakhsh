# Security policy

## Reporting a vulnerability

Please don't open a public issue for a security problem. Report it privately through the **Security** tab of this repository ("Report a vulnerability"), or message us on Telegram at https://t.me/CluvexStudio.

Tell us what you found, how to reproduce it and which version you tested. We'll get back to you as soon as we can, and we're happy to credit you in the fix.

## Supported versions

Security fixes go into the latest release.
